# 研究生课程规划器

一个面向中国科学院大学研究生课程规划的本地优先 Web 应用。它提供课程搜索、非闭卷筛选、学分进度检查、周课表预览、时间冲突检测，以及 JSON 方案备份与恢复功能。

项目首次打开时从 **0 门课程、0 学分**开始，不包含任何个人默认选课方案。课程库放在 `public/data/courses.json`，可以替换为自己的课程数据。

## 功能

- 课程目录：按课程名、课程代码、学科或教师搜索，并按课程类型筛选。
- 所有课程均可加入方案，闭卷课程只作为考核方式提示；“只看非闭卷”是可选筛选条件，默认关闭。
- 选课规划：加入/移出课程，标记是否计入专业学位课。
- 学分检查：显示秋季学分、专业学位课、核心课、专业课和公共选修进度。
- 课表预览：按第 1—19 教学周查看星期、节次、教学周和上课地点。
- 风险提示：检测已选课程时间冲突，并可筛选或排除官方标注为闭卷笔试的课程。
- 数据管理：方案仅保存在浏览器本机，可下载 JSON 备份或恢复备份。

## 本地运行

要求 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

然后打开终端显示的地址，通常是 <http://localhost:3000/>。

生产构建与本地启动：

```bash
npm run build
npm run start
```

## 数据文件

课程数据文件：

```text
public/data/courses.json
```

每门课程至少应包含以下字段：`code`、`name`、`type`、`credit`、`teacher`、`exam`、`place`、`sessions`。`sessions` 中可使用 `day`、`periods`、`weeks` 和 `room` 描述上课安排；无固定时间的线上课程可以使用空数组。

当前仓库中的课程库来自用户提供的 2026—2027 学年课程 Excel 提取数据。公开发布前，请确认课程数据的发布、转载和再分发权限，并在新学年开始前用官方最新数据校验课程信息。

## 规则说明

页面内置的是规划辅助指标，不替代学校、培养单位、导师或选课系统的最终审核。默认展示的博士生规划参考指标包括：秋季至少 10 学分、春季至少 10 学分、夏季至少 2 学分、专业学位课至少 16 学分、总学分至少 38 学分，以及至少 2 门核心课和 2 门专业课。不同学位类型、专业和培养单位可能有额外要求，请以本人官方培养方案为准。
